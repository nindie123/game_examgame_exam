# 顶部数字与底部按钮修复记录

日期：2026-11-01。对应 T02/T10/T13，A02/A10/A11 表现与交互。

## 已确认的原因

1. 原 BoardView.Hud.cs 将文字挂在 SpriteRenderer 按钮背景下。背景按宽、高分别缩放，文字继承不等比缩放，比例失真。
2. 原顶部数字与按钮使用 TextMesh，仅设置 Font，没有同步字体材质，存在字体图集/材质不匹配。截图显示异常与此一致；仍需运行确认最终渲染。
3. 实际查看 UIpanel_outside.png 后确认它是很小的白色圆角块。旧代码把它整体拉伸为棋盘底板，且未设置九宫格，放大了白色轮廓与边缘问题。

## 已保存的修改

- 顶部和按钮改用 Screen Space Overlay Canvas、CanvasScaler、UGUI Image/Text。UGUI 已在项目依赖中，本轮没有引入第三方框架。采用现有 UGUI Text 的动态字体路径，没有依赖 TMP Essential Resources 的导入状态。
- 顶部复用 UIpanel_top_Minigame 图片，图标、数字分别独立布局。数字固定区域居中、深棕粗体，位数改变不移动图标。
- 按钮按“重新开始 / 提示 / 自动演示”居中排列，复用顶部面板图片生成运行时九宫格 Sprite，不改原素材及其 meta。文字不继承背景的非等比缩放。
- 优先查找 Microsoft YaHei、Microsoft YaHei UI、SimHei、Noto Sans CJK SC 系统字体；找不到时使用内置字体和英文标签并记录警告。跨平台中文显示依赖该平台字体，不承诺已嵌入中文字体包。
- 添加悬停颜色、按下缩放与禁用反馈。忙碌时提示禁用；自动演示中允许停止后续自动操作；Restart 保持可用。
- 使用 EventSystem 与 InputSystemUIInputModule 的 Button 事件，移除原手动世界坐标按钮命中逻辑。棋盘点击通过 GraphicRaycaster 查询拦截，避免 UI 点击穿透。
- 背包收集终点从 Canvas 图标位置换算到世界坐标。计数仍读取当前棋盘，缩放动画结束恢复原比例。
- 顶部胜利退场改为 CanvasGroup 淡出及 UI 位移；重开禁用销毁旧 Canvas，重建数字和按钮；事件绑定先解绑再绑定，防止重复监听。
- 棋盘改为深色九宫格底板与细描边，停止放大原白色小图。
- 背景和棋盘保持 SpriteRenderer。相机按宽、高约束为棋盘留出顶部和底部 UI 安全区。
