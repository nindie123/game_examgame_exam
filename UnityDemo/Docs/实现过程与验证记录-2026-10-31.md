## 4. 一次操作的流程

玩家点击相邻可移动对象 → SwapEvaluator 判断 → 无效交换播放回退；有效交换进入 TurnSolver → 提交棋盘快照 → BoardView 播放对应变化 → 消除/生成道具或执行道具队列 → 背包归零则胜利，否则下落补充 → 检查连锁 → 无匹配后检测死局并有限重排 → 恢复输入。

匹配组在原棋盘上先完整识别，再统一清除和生成，不边扫描边删除。道具队列清空前不下落；已入队的道具不会被普通清除直接删除；每个编号只执行一次。胜利后不再启动补充。

重开会增加会话编号、停止控制器与画面的协程、销毁本局表现对象并从配置重新创建棋盘及随机状态。自动演示仅用复制的随机状态计算候选，不消耗实际局的随机流。

## 6. 如何体验

用 Unity 6000.6.7f1 打开 UnityDemo，等待脚本导入，打开 Assets/Scenes/SampleScene.unity，点击 Play。GameBootstrap 在场景加载后自动创建棋盘。

- 点击一个棋子，再点击相邻棋子交换；再次点击选中棋子取消选择。
- 道具也通过相邻交换触发。
- Restart 按钮或 R 键重新开始，动画期间也可重开。
- Hint 显示建议的起点及坐标；坐标是从 1 开始的“行、列”。
- Auto demo 自动挑选合法交换并播放；Stop demo 在当前结算结束后停止继续操作。

固定三步通关路线（行、列均从 1 开始）：
1. (2,6) → (2,7)，结算后剩余 20 个背包。
2. (7,6) → (7,7)，结算后剩余 2 个背包。
3. (8,2) → (8,3)，结算后剩余 0 个背包。

此路线是当前算法和固定种子的验证路线，不是视频原操作序列，也不保证覆盖三类道具的所有生成与使用场景。
