## 6. 可复现运行与构建

1. Unity Hub 打开 UnityDemo，等待编译；测试窗口运行 EditMode。预期 102 项测试通过，本轮尚未取得 Unity 测试 XML。
2. Play 后点击自动演示，按推荐路线通关。R 或“重新开始”重置当前配置；F2 在主关与第二配置间切换。
3. 菜单 GameExam → Build Windows Release，输出 Builds/Windows/GameExam.exe 及配套目录。不能只复制 exe。
4. 也可关闭该工程的编辑器后执行 Tools/Build.ps1；Tools/Build.ps1 -TestOnly 执行 Unity EditMode。失败日志在 Builds/Logs。
5. 发布包验证参数：
   - GameExam.exe -verify-route：正常动画推荐路线。
   - GameExam.exe -verify-route -no-animation：同一结算步骤的无动画显示。
   - GameExam.exe -second-level：第二配置。
6. 推荐路线胜利时，控制器把本次实际消费的步骤与纯规则回放比较，成功日志为 “[Replay] PASS live presentation equals headless steps.”。这只是验证入口，本轮没有该 Unity 运行成功日志。
7. 胜利或错误时写入 Application.persistentDataPath/last-replay.txt。用 ReplayLog.Verify(配置, 文件内容) 重放并定位首个差异。异常记录保留诊断；Verify 的成功路线接口遇到规则 Error 会明确抛错。
8. 发布包最终还需实际检查：16:9、4:3、窄窗；动画中重开；胜利后重开；按钮不穿透；数字清晰、图标收集准确、白边与道具效果正常。
